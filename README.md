## How to run

Requires Node 22+ (the program uses only the Node standard library —
no network, no secrets, no files outside this repository):

```sh
node main.ts
```

This writes deterministic output to `/output/`:

- `spotlight.svg` — the graphic
- `post.txt` — the exact post text
- `POST.json` — copied verbatim from the repository root (the X post URL
  is filled in by the coordinator once the user has published the post)

Running `main.ts` twice produces byte-identical outputs.
